# Fourier Atlas

## Этап 1 — математическое ядро (готово)

```powershell
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install numpy pytest
pytest -v
```

Ядро: `src/fourier_atlas/core` (только NumPy, без Qt).
Нормировка: `c_k = fft(z)[k]/N`, `z(t) = Σ c_k e^{2πikt}`, t ∈ [0,1) — см. docstring `fourier.py`.

## Этап 2 — анимация эпициклов

```powershell
pip install numpy pytest PySide6
pytest -v
python -m fourier_atlas          # из каталога src, либо: set PYTHONPATH=src
```

Запуск из корня проекта: `set PYTHONPATH=src` (PowerShell: `$env:PYTHONPATH="src"`), затем `python -m fourier_atlas`.

Управление: Пуск/Пауза, Сброс, скорость (отрицательная — назад), ползунок фазы, число векторов,
длина следа, переключатели окружностей/векторов/исходного контура. На холсте: колесо — масштаб,
перетаскивание — сдвиг, двойной клик — вписать.

Архитектура: `animation/` (контроллер, viewport) и `data/` не зависят от Qt; `ui/` — только отрисовка и виджеты.
FFT выполняется один раз при загрузке контура; на кадре — только `cumsum` по векторам и срез кэша траектории.

## Ряд Фурье в аналитическом виде

Панель «Ряд Фурье» (нижняя док-панель) показывает формулу текущей цепочки эпициклов в трёх формах:
комплексной `Σ c_k·exp(2πikt)`, полярной `Σ r_k·exp(i(2πkt+φ_k))` и вещественной `x(t), y(t)`.
Текст — выполнимое выражение Python (`i`=1j; `pi`, `exp`, `cos`, `sin` из numpy/math).
Кнопки: копирование текста / LaTeX, сохранение в `.txt` / `.tex`. Модуль: `core/formula.py`.
Формула берётся из той же цепочки, что и анимация, поэтому следует за числом векторов, правками и маской гармоник.
