# Fourier Atlas

## Этап 1 — математическое ядро (готово)

```powershell
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install numpy pytest
pytest -v
```

Ядро: `src/fourier_atlas/core` (только NumPy, без Qt).
Нормировка: `c_k = fft(z)[k]/N`, `z(t) = Σ c_k e^{2πikt}`, t ∈ [0,1) — см. docstring `fourier.py`.

## Этап 2 — анимация эпициклов

```powershell
pip install numpy pytest PySide6
pytest -v
python -m fourier_atlas          # из каталога src, либо: set PYTHONPATH=src
```

Запуск из корня проекта: `set PYTHONPATH=src` (PowerShell: `$env:PYTHONPATH="src"`), затем `python -m fourier_atlas`.

Управление: Пуск/Пауза, Сброс, скорость (отрицательная — назад), ползунок фазы, число эпициклов (поле ввода 0–1024; 0 — только центр),
длина следа, переключатели окружностей/векторов/исходного контура. На холсте: колесо — масштаб,
перетаскивание — сдвиг, двойной клик — вписать.

Архитектура: `animation/` (контроллер, viewport) и `data/` не зависят от Qt; `ui/` — только отрисовка и виджеты.
FFT выполняется один раз при загрузке контура; на кадре — только `cumsum` по векторам и срез кэша траектории.

## Ряд Фурье в аналитическом виде

Панель «Ряд Фурье» (нижняя док-панель) показывает формулу текущей цепочки эпициклов в трёх формах:
комплексной `Σ c_k·exp(2πikt)`, полярной `Σ r_k·exp(i(2πkt+φ_k))` и вещественной `x(t), y(t)`.
Текст — выполнимое выражение Python (`i`=1j; `pi`, `exp`, `cos`, `sin` из numpy/math).
Кнопки: копирование текста / LaTeX, сохранение в `.txt` / `.tex`. Модуль: `core/formula.py`.
Формула берётся из той же цепочки, что и анимация, поэтому следует за числом векторов, правками и маской гармоник.

## Этап 3 — геоданные и страны

1. Скачайте базу стран (Natural Earth, public domain):
   ```powershell
   python scripts\fetch_countries.py              # 110m, ~0.8 МБ
   python scripts\fetch_countries.py --scale 50m  # подробнее
   ```
   Файл попадает в `src/fourier_atlas/data/countries/`. Вручную: положите туда
   `ne_110m_admin_0_countries.geojson` или задайте `FOURIER_ATLAS_COUNTRIES=<путь>`.
2. Запуск: `python -m fourier_atlas`. Выбор страны — выпадающий список с поиском по вводу.
3. Импорт: кнопка «Импорт файла…» — GeoJSON, Shapefile (.shp [+.dbf/.prj/.cpg]), SVG, CSV/TXT.
   Файл читается в фоновом потоке, интерфейс не блокируется.

Правила подготовки контура (`geo/prepare.py`): берётся внешнее кольцо выбранной ЧАСТИ
(1 — самая большая по площади; острова и эксклавы — части 2, 3, …); долготы разворачиваются
(антимеридиан), проекция «равнопромежуточная» (x = λ·cos φ0) либо plate carrée; обход — против
часовой стрелки; SVG разворачивается по оси Y. Дыры полигонов игнорируются.
Форматы читаются без GeoPandas/Shapely (лёгкая сборка .exe); CSV считается географическим,
только если в заголовке есть lon/lat.

## Этап 4 — спектр, коэффициенты, сходимость, сравнение

Нижняя панель «Анализ» (вкладки): Ряд Фурье · Спектр · Коэффициенты · Сходимость · Сравнение.
Все вкладки синхронизированы через единый редактор спектра (`analytics/editor.py`): любая правка
один раз пересчитывает цепочку эпициклов и кэш траектории, затем обновляет анимацию, формулу и панели.

- **Спектр:** амплитуды |c_k| и фазы arg c_k; двойной клик по линии включает/отключает гармонику;
  синий — включена, оранжевый — изменена вручную, серый — отключена; логарифмическая шкала.
- **Коэффициенты:** таблица (Re, Im, |c|, arg); ячейки Re/Im/|c|/arg редактируются, флажок «Вкл» включает
  гармонику; поле «Значение» принимает `a+bi`, `r@φ` (рад) или `r@φ°`. Отмена/повтор (Ctrl+Z / Ctrl+Y),
  сброс выбранных/всех. Исходный спектр никогда не изменяется (правки хранятся отдельно).
- **Сходимость:** относительная ошибка (RMSE, % диагонали контура) от числа эпициклов: по убыванию |c|
  (как выбирает анимация) и по частотной полосе; маркер — текущее состояние (с правками); подсказка,
  сколько эпициклов нужно для 5 / 1 / 0.1 / 0.01 %. Кривые считаются по теореме Парсеваля, без реконструкций.
- **Сравнение:** исходный и восстановленный контуры, RMSE, максимальная ошибка, расстояние Хаусдорфа
  (в единицах нормированного контура и в % диагонали), опционально отрезки отклонений.
- Число эпициклов — поле ввода 0–1024 (0 — только центр).

### Контекстное меню гармоник (правая кнопка)
Правый клик по гармонике открывает меню: «Изменить значение…», «Включить», «Отключить», «Сбросить значение».
Работает в трёх местах: в таблице коэффициентов (по строке; при выделении нескольких строк меню применяется ко всем),
на графике спектра (по ближайшей линии) и на самой анимации (по окружности или вектору эпицикла; на время
меню анимация ставится на паузу). Окружности, не видимые на экране (радиус < 1 px), на холсте не выбираются.
