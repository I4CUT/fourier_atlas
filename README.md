```powershell
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install numpy pytest

```

Нормировка: `c_k = fft(z)[k]/N`, `z(t) = Σ c_k e^{2πikt}`, t ∈ [0,1) — см. docstring `fourier.py`.

```powershell
pip install numpy pytest PySide6

python -m fourier_atlas          # из каталога src, либо: set PYTHONPATH=src
```

Запуск из корня проекта: `set PYTHONPATH=src` (PowerShell: `$env:PYTHONPATH="src"`), затем `python -m fourier_atlas`.

Управление: Пуск/Пауза, Сброс, скорость (отрицательная — назад), ползунок фазы, число эпициклов (поле ввода 0–1024; 0 — только центр),

перетаскивание — сдвиг, двойной клик — вписать.

FFT выполняется один раз при загрузке контура; на кадре — только `cumsum` по векторам и срез кэша траектории.

## Ряд Фурье в аналитическом виде

Панель «Ряд Фурье» (нижняя док-панель) показывает формулу текущей цепочки эпициклов в трёх формах:
комплексной `Σ c_k·exp(2πikt)`, полярной `Σ r_k·exp(i(2πkt+φ_k))` и вещественной `x(t), y(t)`.
Текст — выполнимое выражение Python (`i`=1j; `pi`, `exp`, `cos`, `sin` из numpy/math).
Кнопки: копирование текста / LaTeX, сохранение в `.txt` / `.tex`. Модуль: `core/formula.py`.
Формула берётся из той же цепочки, что и анимация, поэтому следует за числом векторов, правками и маской гармоник.

## Этап 3 — геоданные и страны

1. Скачайте базу стран (Natural Earth, public domain):
   ```powershell
   python scripts\fetch_countries.py              # 110m, ~0.8 МБ
   python scripts\fetch_countries.py --scale 50m  # подробнее
   ```
   Файл попадает в `src/fourier_atlas/data/countries/`. Вручную: положите туда
   `ne_110m_admin_0_countries.geojson` или задайте `FOURIER_ATLAS_COUNTRIES=<путь>`.
2. Запуск: `python -m fourier_atlas`. Выбор страны — выпадающий список с поиском по вводу.
3. Импорт: кнопка «Импорт файла…» — GeoJSON, Shapefile (.shp [+.dbf/.prj/.cpg]), SVG, CSV/TXT.
   Файл читается в фоновом потоке, интерфейс не блокируется.

Правила подготовки контура (`geo/prepare.py`): берётся внешнее кольцо выбранной ЧАСТИ
(1 — самая большая по площади; острова и эксклавы — части 2, 3, …); долготы разворачиваются
(антимеридиан), проекция «равнопромежуточная» (x = λ·cos φ0) либо plate carrée; обход — против
часовой стрелки; SVG разворачивается по оси Y. Дыры полигонов игнорируются.
Форматы читаются без GeoPandas/Shapely (лёгкая сборка .exe); CSV считается географическим,
только если в заголовке есть lon/lat.

## Этап 4 — спектр, коэффициенты, сходимость, сравнение

Нижняя панель «Анализ» (вкладки): Ряд Фурье · Спектр · Коэффициенты · Сходимость · Сравнение.
Все вкладки синхронизированы через единый редактор спектра (`analytics/editor.py`): любая правка
один раз пересчитывает цепочку эпициклов и кэш траектории, затем обновляет анимацию, формулу и панели.

- **Спектр:** амплитуды |c_k| и фазы arg c_k; двойной клик по линии включает/отключает гармонику;
  синий — включена, оранжевый — изменена вручную, серый — отключена; логарифмическая шкала.
- **Коэффициенты:** таблица (Re, Im, |c|, arg); ячейки Re/Im/|c|/arg редактируются, флажок «Вкл» включает
  гармонику; поле «Значение» принимает `a+bi`, `r@φ` (рад) или `r@φ°`. Отмена/повтор (Ctrl+Z / Ctrl+Y),
  сброс выбранных/всех. Исходный спектр никогда не изменяется (правки хранятся отдельно).
- **Сходимость:** относительная ошибка (RMSE, % диагонали контура) от числа эпициклов: по убыванию |c|
  (как выбирает анимация) и по частотной полосе; маркер — текущее состояние (с правками); подсказка,
  сколько эпициклов нужно для 5 / 1 / 0.1 / 0.01 %. Кривые считаются по теореме Парсеваля, без реконструкций.
- **Сравнение:** исходный и восстановленный контуры, RMSE, максимальная ошибка, расстояние Хаусдорфа
  (в единицах нормированного контура и в % диагонали), опционально отрезки отклонений.
- Число эпициклов — поле ввода 0–1024 (0 — только центр).

### Контекстное меню гармоник (правая кнопка)
Правый клик по гармонике открывает меню: «Изменить значение…», «Включить», «Отключить», «Сбросить значение».
Работает в трёх местах: в таблице коэффициентов (по строке; при выделении нескольких строк меню применяется ко всем),
на графике спектра (по ближайшей линии) и на самой анимации (по окружности или вектору эпицикла; на время
меню анимация ставится на паузу). Окружности, не видимые на экране (радиус < 1 px), на холсте не выбираются.

## Этап 5 — экспорт, проекты, настройки, журнал

```powershell
pip install Pillow imageio imageio-ffmpeg    # (или pip install -r requirements.txt)
```

**Меню «Экспорт»:** PNG (текущий кадр), SVG (вектор, текущий кадр), GIF и MP4 (один полный оборот; задаются размер,
частота кадров и длительность), CSV коэффициентов и CSV контуров (исходный + восстановленный + ошибка по точкам).
Экспорт выполняется в фоновом потоке: интерфейс не блокируется, есть индикатор прогресса и кнопка «Отмена».
Кадры пишутся потоково (память не растёт с числом кадров); файл сначала пишется во временный `*.part.*` и
переименовывается только после успешного завершения (при отмене/ошибке недописанных файлов не остаётся).
Экспорт использует копию спектра на момент запуска — правки во время экспорта на него не влияют.
Для MP4 используется ffmpeg из пакета `imageio-ffmpeg` (кодек H.264, yuv420p; размеры округляются до чётных).

**Проекты (JSON):** «Файл → Сохранить/Открыть проект» (`*.fatlas.json`). В проект входят контур целиком
(поэтому он открывается без базы стран и исходных файлов), изменённые коэффициенты, отключённые гармоники,
число эпициклов, скорость, длина следа и фаза. Версия формата проверяется; повреждённый файл даёт понятное сообщение.

**Настройки** (`%APPDATA%\FourierAtlas\settings.json`, либо `FOURIER_ATLAS_HOME`): последняя страна, проекция,
параметры анимации, переключатели слоёв, параметры экспорта, последние каталоги, геометрия окна. Недопустимые
значения заменяются значениями по умолчанию; повреждённый файл не мешает запуску.

**Журнал:** `…\FourierAtlas\logs\fourier_atlas.log` (ротация 1 МБ × 3). Необработанные исключения логируются
и показываются в окне; путь к журналу — «Справка → Где находится журнал».

## Звук по спектру контура

Вкладка «Звук» (нижняя панель) и пункты меню «Экспорт → Звук WAV…», а также MP4 со звуком.

**Модель.** Контур проигрывается как периодическая волна с основной частотой f0 (по умолчанию 110 Гц):
`L(τ) = Re z(f0·τ)`, `R(τ) = Im z(f0·τ)`. Гармоника k звучит на частоте |k|·f0, громкость — |c_k|, фаза — arg c_k.
Если левый канал подать на X, а правый на Y осциллографа (режим XY), на экране рисуется сам контур страны.
Центр контура (k = 0) не звучит. Режим «Моно» — (Re z + Im z)/2. Гармоники выше 20 кГц отбрасываются (без алиасинга).

**Режимы.**
- *Тембр контура* — зацикленное проигрывание; число гармоник = число эпициклов в анимации; отключение гармоник и
  правки коэффициентов меняют звук сразу (пока звучит, буфер пересобирается с задержкой ~0,2 с).
- *Наращивание гармоник* («сходимость на слух») — гармоники подключаются по убыванию амплитуды (1, 2, 3, …, N),
  все шаги нормируются одним множителем, поэтому слышно реальное нарастание насыщенности.
- *MP4 со звуком* — тембр, либо наращивание: в видео число эпициклов растёт синхронно со звуком.

**Точность.** Подбирается целое число периодов P и длина L = round(P·sr/f0): гармоника k попадает точно в бин k·P
обратного БПФ, поэтому один `ifft` даёт точный сигнал, а буфер зацикливается без щелчка. Фактическая f0' отличается
от заданной менее чем на ~1e-5 (относительно). Модуль: `audio/synth.py` (без Qt). Проигрывание — `QSoundEffect`
(QtMultimedia, входит в PySide6).

### Режим «Мелодия»

Каждый из крупнейших эпициклов играет свою ноту, когда его вектор проходит направление «вверх»:
`t_m = ((π/2 − arg c_k)/(2π) + m)/k (mod 1)`, m = 0…|k|−1. Один оборот контура = один такт (`bar_seconds`),
гармоника k играет |k| нот за такт (полиритмия 1:2:3:…), фазы arg c_k задают рисунок ритма, громкость ноты — |c_k|,
направление вращения — панорама (против часовой — вправо, по часовой — влево).

Музыкальные соглашения (выбор автора, всё настраивается во вкладке «Звук»): высота растёт с |k| среди выбранных
голосов; лад (минорная/мажорная пентатоника, натуральный минор, мажор, хроматика) и тоника; число голосов 1–32;
длина такта 1–30 с; квантование по сетке (1/4 … 1/32; по умолчанию выключено — ритм «честный»); голоса быстрее
8 нот/с и тише 1e-4 от крупнейшего не играют. Тембр — простая «маримба».

Экспорт: «Мелодия MIDI…» (формат 0, 4/4, темп из длины такта, маримба; каналы 0/1 — панорама влево/вправо),
«Звук WAV: мелодия…», MP4 «Со звуком: мелодия» — в видео один оборот = один такт, в момент каждой ноты вектор и
окружность соответствующего эпицикла вспыхивают (в видео показаны ровно те эпициклы, что играют).
Демо-файлы: папка `demo/` (сердце и звезда: WAV + MID).

### Звук из командной строки (без окна)
```powershell
python scripts\fetch_countries.py                       # один раз: база стран
python scripts\make_audio.py --country Italy --mode melody --out italy_melody.wav --midi italy.mid
python scripts\make_audio.py --country Italy --mode timbre --seconds 8 --out italy_timbre.wav
python scripts\make_audio.py --file my_country.geojson --mode buildup --out build.wav
```
Режимы: `timbre`, `buildup`, `melody`; параметры мелодии — `--voices`, `--bar-seconds`, `--scale`, `--root`, `--quantize`;
`--part N` выбирает часть контура по площади (1 — материк). Модуль: `fourier_atlas/cli_audio.py`.

### Сохранение звука и мелодии
- Вкладка «Звук» → «Сохранить в файл»: «Мелодия → WAV», «Мелодия → MIDI», «Тембр → WAV», «Наращивание → WAV».
  Те же команды есть в меню «Экспорт». Откроется диалог (длительность; для мелодии — число тактов считается из
  длительности и длины такта), затем выбор файла; запись идёт в фоне с прогрессом.
- Без окна (после `python scripts/fetch_countries.py`):
  `python scripts/make_audio.py --country Italy --mode melody --out italy_melody.wav --midi italy.mid`
  Страну можно искать по имени/коду (Italy, Италия, ITA) либо взять из файла (`--file`). Параметры: `--mode
  timbre|buildup|melody`, `--voices`, `--bar-seconds`, `--scale`, `--root`, `--quantize`, `--seconds`, `--f0`, `--mono`.
